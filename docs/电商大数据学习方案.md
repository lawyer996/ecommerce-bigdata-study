# 电商+大数据 学习实战方案（基于GitHub项目仓库）
> 适用：大数据专业，面向求职，4阶段循序渐进学习，所有代码、数据集、实验报告都托管到当前GitHub仓库。

## 项目目标
以电商业务场景（用户浏览、点击、下单、支付、复购、商品推荐）为载体，完整练习大数据全链路技术栈，最终产出一套可写进简历的实战项目，仓库作为作品集。

## 仓库目录说明
- stage1_data_analysis：阶段1 Python电商离线数据分析
- stage2_offline_dw：阶段2 Hadoop+Hive 电商离线数据仓库
- stage3_real_time：阶段3 Flink 电商实时数据流处理
- stage4_recommend：阶段4 电商商品推荐系统（机器学习）
- docs：文档（本方案、实验报告、踩坑笔记）
- dataset：电商数据集
- scripts：shell、python通用脚本

# 阶段1：Python电商数据分析（基础，约2周）
## 学习目标
掌握数据清洗、指标计算、可视化，理解电商核心业务指标：UV、PV、转化率、客单价、复购率。
## 技术栈
Python、Pandas、Numpy、Matplotlib/Seaborn
## 数据集
公开电商用户行为数据集（淘宝/京东用户行为数据集）
## 任务清单
1. 数据集加载、缺失值、异常值清洗
2. 统计PV、UV、日活、时段流量分布
3. 商品热销排行、用户购买转化漏斗分析
4. 用户RFM分层（价值用户划分：高价值、流失、新客）
5. 可视化图表绘制，输出数据分析报告
## 产出物
- python分析脚本放在stage1_data_analysis/
- 数据分析报告.md写入stage1目录
- 提交到github，每完成一个小任务单独commit

## 阶段2：Hadoop+Hive 电商离线数仓（进阶，约3周）
### 学习目标
理解数据仓库分层（ODS、DWD、DWS、ADS），构建电商离线数仓，做每日离线统计。
### 技术栈
Hadoop(HDFS+MapReduce)、Hive、MySQL、Sqoop
### 任务清单
1. 搭建Hadoop伪分布式环境
2. 数据分层设计
   - ODS：原始用户行为日志
   - DWD：明细层，清洗用户点击、下单、支付明细
   - DWS：用户/商品聚合层，用户日行为汇总、商品销售汇总
   - ADS：应用层，报表指标（日GMV、下单转化率）
3. Hive SQL开发，建表、分区、分桶
4. 数据导出到MySQL，供报表展示
### 产出物
- Hive建表SQL脚本放在stage2_offline_dw
- 数仓分层设计文档写入docs
- 测试结果、踩坑笔记提交github

## 阶段3：Flink实时电商数据流（高阶，约3周）
### 学习目标
实时处理电商数据流，实时统计在线指标。
### 技术栈
Kafka、Flink(Java/Scala/Python)、Redis
### 任务清单
1. Kafka接收模拟电商实时日志（用户点击、下单）
2. Flink消费kafka流数据
3. 实时指标：实时UV、实时销量、实时热门商品排行榜
4. 窗口计算（滚动窗口、滑动窗口）、CEP复杂事件处理（下单后未支付超时订单检测）
5. 结果写入Redis做实时大屏展示
### 产出物
- Flink代码、kafka脚本放在stage3_real_time
- 实时指标设计文档提交docs

## 阶段4：电商推荐系统（项目收尾，约2周）
### 学习目标
实现简单商品推荐，理解协同过滤、用户画像。
### 技术栈
Python、Spark MLlib、Redis
### 任务清单
1. 构建用户画像：用户浏览、购买、偏好标签
2. 实现协同过滤推荐算法（基于用户/基于商品）
3. 离线计算推荐结果存入Redis
4. 简单推荐效果评估
### 产出物
推荐系统代码、算法说明文档放在stage4_recommend
