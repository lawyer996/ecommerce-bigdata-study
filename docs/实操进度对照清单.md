## 六、建议推进顺序（本地可执行优先）

1. **补齐阶段1周2**：装 MySQL → 清洗数据入库 → GMV/RFM/转化率 SQL（收益最大，全部本地可跑）
2. **补齐阶段1周3**：Streamlit 大屏 + stage1 README + week1~3 笔记
3. **不依赖集群的先手棋**：ADS 层 SQL、数仓建模文档、Kafka producer 模拟脚本、ECharts 静态大屏
4. **集群部分**（Hadoop/Hive/Spark/Kafka）：搭虚拟机或租云服务器后集中推进
5. **阶段4**：下载天池 UserBehavior 数据集 → 本地跑 ALS（可用 implicit 库）→ 评估指标
