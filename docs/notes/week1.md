# 周记 · Week1（阶段1：数据清洗）

## 本周做了什么
- 接入真实数据集：天池 UserBehavior 子集 485,730 条（2017-11-26 单日，23.2 万用户）
- 完成四步清洗（`clean_real_data.py`）：缺失值剔除 → 行为枚举过滤（pv/fav/cart/buy）→ 时间范围过滤 → 全字段去重

- 用 pandas 跑通真实 KPI（`real_data_kpi.py`）：PV 43.4 万 / UV 23.2 万 / 购买率 2.57%，输出时段曲线 + 真实漏斗图

## 踩了什么坑
